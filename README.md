# Wichteln 🎁

Ein einfacher Wichtelautomat, der komplett im Browser läuft und über GitHub Pages ausgeliefert wird.

## So geht's

1. Namen eintragen. Optional kannst du Budget, Datum der Bescherung und Ausnahmen angeben (z. B. „Anna - Ben“, dann ziehen sich die beiden nicht gegenseitig).
2. Auf „Auslosen“ drücken.
3. Jedem seinen Link schicken. Wer den Link öffnet, sieht, wen er beschenkt.

Der Organisator sieht die Zuordnung nicht und kann selbst mitmachen.

## Datenschutz

Es gibt keinen Server und keine Datenbank. Die Zuordnung steckt verschleiert im `#`-Teil des Links, und der wird nie an einen Server geschickt. Der Link ist nur verschleiert, nicht sicher verschlüsselt. Für Wichteln unter Freunden reicht das.

## Veröffentlichen

Settings → Pages → Branch `main`, Ordner `/ (root)`. Danach ist die Seite unter https://chrdienersberger-blip.github.io/wichteln/ erreichbar.
